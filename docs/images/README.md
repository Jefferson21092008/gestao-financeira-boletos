# Capturas da interface

As imagens desta pasta foram produzidas exclusivamente para documentação e portfólio com um banco de dados temporário de demonstração.

Todos os nomes de empresas, CNPJs, códigos de pagamento, valores, endereços, telefones e demais informações visíveis são dados sintéticos. Nenhuma informação operacional real deve ser adicionada a esta pasta.

Ao atualizar as capturas, mantenha a mesma regra: use somente dados fictícios e revise a imagem antes do commit.
